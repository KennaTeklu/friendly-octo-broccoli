# 12 - Roadmap

v31 through v40. Each batch small enough to audit.

## v31 - Foundation

Install v30 on phone. Fix whatever is broken. Re-tighten coach coverage test. Commit these architecture documents. Ship as v31 / 2.0.1.

## v32 - State model

One state tree. Events. Versions. Provenance. Export contract. Four-axis field query. Top 100 exercises with authored stimulus defaults. No coaches changed. Ship as v32 / 2.1.0.

## v33 - Engines

Twelve engine families, each implemented once, each testable in isolation. Each produces PrescriptionFragments. Ship as v33 / 2.2.0.

## v34 - Exercise coaches rebuilt

Each exercise coach becomes a reconciler over fragments. CoachRegistry resolves every library exercise to a specific coach. Zero fallbacks. Coverage test strict. Ship as v34 / 2.3.0.

## v35 - Declaration pattern

Every exercise card declares intent first. Chips visible. Coach sentence. Coach, go / Change. Tuning becomes a dialogue with preview. Ship as v35 / 2.4.0.

## v36 - Healing chronicle

Auto-written weekly, block, season entries. Five healing moves. Hallucination constraint. Platitude penalty. Chronicle as a first-class surface. Ship as v36 / 2.5.0.

## v37 - Five surfaces

Today, Session, Chronicle, Goals, You. One continuous scroll. Tab bar as compass, not directory. Ship as v37 / 2.6.0.

## v38 - Lifecycle

Phase classifier (HMM). Phase-aware personas. Comeback protocols. Season boundaries. Ship as v38 / 2.7.0.

## v39 - Guardian and meta

Envelope enforcement via Control Barrier Function. Meta-coach for drift detection. Rollback. Forgotten state. Witness. Handoff. Exit. Ship as v39 / 2.8.0.

## v40 - Portability

Export contract live. Signed events. Cross-device reconciliation. Identity keypair exportable as mnemonic. Ship as v40 / 3.0.0.

## Beyond

Coaches added or refined. Surfaces polished. Rules sharpened. The spiral advances.

The app is not a set of features. It is a system to be grown.
