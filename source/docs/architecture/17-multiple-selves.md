# 17 - Multiple selves

The user is not one person across time. The user is a population of selves within one body, each with its own state.

## The selves

- Monday-morning self is not Friday-night self.
- Rested self is not sleep-deprived self.
- Sick self is not peak self.
- Post-injury self is not pre-injury self.
- Traveling self is not home-gym self.
- Cut self is not bulk self.
- Motivated self is not quiet self.

## How the system tracks them

The dossier does not track one trajectory. It tracks multiple, keyed by context:

- Context = (phase, readiness band, environment, arc week, life state)
- Each context has its own recent performance history
- Each context has its own calibration

When the user arrives at a session, the coach first identifies which self is here. Then it prescribes for that self.

## Why it matters

A coach who prescribes for one average user will consistently miss both ends of the range. The motivated, rested self gets under-pushed. The tired, stressed self gets over-pushed. Neither is served.

The correct coach recognizes which self is present and prescribes for that self, not the average.

## The rule

- Never prescribe to the average self when you can see which self is here.
- Never assume yesterday's self is today's self.
- Never shame the tired self. The tired self is not a failure state. It is a real state.
- Never celebrate only the peak self. Progress in the tired self is also progress.

## Storage

Self states are derived from context. They are not stored as separate entities. They are views over the state tree.

The coach reads the current context, selects the self view, prescribes.
