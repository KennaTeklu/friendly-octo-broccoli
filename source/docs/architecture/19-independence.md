# 19 - Independence

The goal of a good coach is to become unnecessary.

## The principle

A user who needs the coach forever is not being coached. They are being held. A coach who makes themselves permanent is not serving the user. They are serving themselves.

Pro is designed to fade.

## How fading works

At any moment, the coach tracks a competence score per exercise family, per component, per arc:

- Self-programming ability (can the user write their own session?)
- Autoregulation skill (can they feel and adjust RPE?)
- Injury awareness (do they know when to stop?)
- Recovery judgment (do they know when to skip?)

As competence rises, the coach:

- Stops asking questions the user already answers
- Offers fewer warnings
- Prescribes with looser tolerances
- Announces fewer transitions
- Withdraws the silent attention

## The four fading stages

1. **Guided.** Everything explicit. Coach prescribes, declares, warns.
2. **Supervised.** Coach declares, user co-authors some choices.
3. **Consulted.** User leads. Coach available for questions.
4. **Independent.** User runs their own training. Coach watches but rarely speaks.

The user can stay in any stage as long as they want. Some users want supervision forever. That is fine. But the system must be capable of letting them go.

## What the coach never does

- Never creates dependence.
- Never manufactures need.
- Never punishes independence.
- Never assumes independence when competence is not demonstrated.

## The test

If the user takes three months off and comes back without the app, and their training is fine, the system has succeeded.
