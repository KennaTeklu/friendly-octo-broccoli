# 08 - The loops

Not linear. Not a loop. A helix.

## Forward pass is linear

Within one prescription: Intent -> Arc -> Component targets -> Exercise selection -> Prescription -> Chronicle.

Acyclic. Auditable. Every prescription is a pure function of its inputs.

## Full system is a loop

After the session, response writes back to dossier. Next session reads updated dossier.

Prescription -> Session -> Response -> Dossier -> Next.

## Why a loop is still not enough

1. The state accumulates. Every session appends.
2. The learning compounds. Coach versions change.
3. The rates differ. Five loops, nested.
4. It anticipates. Forecasts change the plan before the plan runs.

A circle does not do these things. A spiral does.

## The five loops

| Loop | Period | Adjusts |
|---|---|---|
| Intra-set | Seconds | Form, tempo, breath, failure decision |
| Inter-set | Minutes | Rest, load for next set |
| Session | Hour | Volume, order, end point |
| Arc | Weeks | Component targets, progression rate |
| Season | Months to years | Which arc, when to deload, when to peak |

## Rule

Fast loops inform slow loops. Never the reverse. An intra-set observation can change the session. It cannot instantly change the arc.

Slow loops constrain fast loops. The arc sets the envelope within which the session operates.

## The helix

Axis is time. Each turn is one training cycle. Distance from axis is the state of the system. You do not return to the same point. You return to a higher point on the spiral.

## The two spirals

One is the user's physical state over time. One is the coach's model of the user over time. The coach's spiral trails the user's, always catching up. Occasionally it anticipates.

## Co-evolution

The user changes. The coach changes. Each is changed by the other. Neither is the same system they were six months ago. They have co-evolved into a different pair.
