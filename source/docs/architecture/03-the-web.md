# 03 - The web

The seven layers describe a stack. A stack is a machine. Machines are fragile.

A training life is not a machine. It is a habitat. It is a web.

## The 14 nodes we forgot

1. Body as signal channel - soreness, sleep, HRV, cycle, mood. Not just response to session.
2. Environment - gym, home, hotel, outdoors. Equipment, temperature, altitude.
3. Life - work stress, sleep debt, children, exams, moving, grief.
4. Philosophy - why training? Health, longevity, aesthetics, performance, identity?
5. Permission - who authorized the coach? To be told or asked?
6. Exit - how does the user leave gracefully?
7. Handoff - to physio, meet coach, doctor, new trainer.
8. Independence - the goal is to become unnecessary. The system must fade.
9. Multiple selves - Monday-morning user is not Friday-night user.
10. Witness - partner, physio, buddy, parent. Training is social.
11. Forgetting - some things must be released.
12. Meta-coach - who watches the coach? Drift detection, correction.
13. Two-body problem - training partners, coupled sessions.
14. Non-training life - the reason training exists.

## Without them

A stack. Vertical. Efficient. Fragile. It works when the user is a machine in a perfect gym with no life, one philosophy, one self, no exit. That is not a user. That is a simulation.

## With them

A web. Every node sources and sinks. No top, no bottom. Only the pattern.

## Six properties of the web

1. No primary direction.
2. Every node is both source and sink.
3. Redundant paths.
4. Continuous feedback at every scale.
5. Emergence.
6. Resilience through multiplicity.

## What this means

A stack is correct when it does the right thing. A web is correct when it is in right relationship with everything it touches.

A stack is finished when features ship. A web is never finished because its nodes are never finished.

A stack is described by its spec. A web is described by its habits.
