This folder is the implementation book. Not the vision
(that is source/docs/architecture/). Not the batch
process (that is source/docs/meta/). This is how the
system actually works, in the order it is built.

## The one-sentence summary

Hardcoded, cited, per-exercise knowledge flows into a
shared field that learns each body, and the coaches
read that field to prescribe the next session.
