# The shape — linear, loop, spiral, web

## Linear

The forward pass of one prescription. One direction. No feedback. Auditable end to end.

- Overall Coach reads arc and intent.
- Component coaches return targets.
- Library Selector picks exercises.
- Exercise coach collects fragments.
- Reconciler produces one prescription.
- Card renders it.

Also linear: the batch pipeline. Symptom -> batch file -> prompt -> developer -> zip -> verify -> install -> test -> accept -> push. Same shape every batch.

Also linear: the verification block. One hash, one version, one cert.

## Loop

Many parts are loops. Each returns close to where it started. Not exactly.

- Post-session write-back. Session -> event -> dossier -> next session reads dossier. Hours.
- Arc adjustment. Week -> arc state -> next week's targets. Weeks.
- Coach calibration. Coach reads its own history with this user. Months.
- Comeback. Absence -> comeback arc -> return -> resolve. Irregular.
- Chronicle writing. Session lines -> weekly paragraph -> block summary -> season. Compressing.
- Silence decision. Importance x surprise x disruption -> speak or suppress. Seconds.
- Drift reconciliation. Expectation vs reality, prescription vs reality, story vs log, intent vs intent. Per session to per season.
- Stimulus field learning. Every session appends. Posterior sharpens. Continuous.

## Spiral

Loops that do not return to the same point. State accumulates.

- The relationship. User and coach both change. Not the same system six months later.
- The dossier. Every session appends. Deeper history, different training.
- The chronicle. Each entry written from a different vantage.
- Coach versions. Each bump changes rules for new arcs. Old arcs pinned.
- The stimulus field per user. Asymptote is a specific body.

## Web

Three distinct webs.

First — the 14 nodes from 03-the-web.md. Body, environment, life, philosophy, permission, exit, handoff, independence, multiple selves, witness, forgetting, meta-coach, two-body, non-training life. Each is source and sink. No top, no bottom.

Second — the coach cooperation graph. Coaches, field, dossier, arc. Each reads from a subset, writes to a subset. Redundant paths.

Third — the reconciliation web. Four views of the same person. Each read along a different axis. Shared substrate, not a pipeline.

## The 12 layers

1. Guardian — envelope, safety, refusal.
2. Lifecycle — app state, sessions.
3. Decision — which coach decides what.
4. Data — state model, events, persistence.
5. Composition — assembling a session from components.
6. Interaction — UI, cards, tune, declaration surface.
7. Field — the stimulus field over the joint space.
8. Loops — fast/slow feedback at different rates.
9. Reconciliations — four drifts, four healing paths.
10. Chronicle — narration and healing.
11. Declaration — the coach speaking first.
12. Web — the shape of the system overall.

Proportion:
- Linear: 1 layer (composition).
- Loop: 5 layers (data write-back, arc, coach calibration, chronicle writing, silence).
- Spiral: 4 layers (relationship, dossier, coach versions, field learning).
- Web: 2 layers (the 14 nodes, the reconciliation substrate).

## One line

Forward pass is linear. Everything after the session is a loop. Every loop is a spiral because state accumulates. The system is a web because nodes that feed the loops have redundant paths and no primary direction. The plan is the pattern, not a command.

The spine is thin on purpose. If the forward pass looped, nothing could be verified. Everything that learns is off the spine. Everything that is trusted is on it, in one straight line.
